# Public asset mapping

这个源码快照只保留适合代码审阅的 `public/data/`、VR180 运行时代码和小型通用图标。

为避免在同一仓库重复保存数百 MB 媒体，源码运行时所需的以下目录在 GitHub 发布仓库根目录中维护：

- `videos/`
- `inattentive-assets/`
- `case-shop/`
- `cover/`
- `VR180/assets/`

本地完整开发目录仍使用标准的 `source/public/...` 结构；从 GitHub 源码快照本地运行前，应把上述根目录资产放回 `source/public/` 对应位置。
